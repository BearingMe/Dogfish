# Dogfish: Skyrim Conquest Research

An exploratory research project investigating **Conquest of Skyrim**, a Skyrim Special Edition mod created by galvatron304 ([Nexus Mods #65628](https://www.nexusmods.com/skyrimspecialedition/mods/65628)).

## Overview

*Conquest of Skyrim* introduces grand strategy systems into Skyrim Special Edition, including faction management, territorial conquest, warfare, politics, and economy.

The objective of this project is to understand the mod through systematic investigation. This is an exploratory research project, not an implementation project.

## Research Approach

Research is conducted across two parallel tracks:

1. **Human Playtesting**: A human researcher playtests the mod, documenting gameplay observations, reproduction steps for bugs, and system discoveries.
2. **AI Investigations**: AI agents independently investigate publicly available documentation, technical characteristics, dependencies, and relevant Skyrim modding systems.

## Project Status

**Status**: Initial Research Phase

The project is in its bootstrap phase. No mod implementation, script authoring, or technical investigations have started yet.
